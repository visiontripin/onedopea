# ONEDOPEA · полная страница Dope из синей капсулы (прототип)

Автономный HTML-прототип: из синей пилюли выпрыгивает кот-логотип, приземляется на
**первую публикацию**, карабкается вверх и занимает **место фото профиля**. После этого
лента оживает: в «фото профиля» каждой публикации живёт кот со своим сценарием.

интернет не нужен (обложка аудио-релиза SoundCloud подгружается с их CDN, но при
отсутствии сети показывается аккуратная заглушка «ENOUGH Z»).

## Что происходит по шагам

| Время | Сцена | Что видно |
| --- | --- | --- |
| 0 – 1.2 с | Синяя капсула откручивается | Крышка сходит, внутри «зев» капсулы |
| ≈ 1.2 с | Превью ленты | Страница Dope уже видна, но размыта — коту есть куда бежать |
| ≈ 1.3 с | Кот выпрыгивает | Масштаб 30 % → 100 %, дуга из горлышка |
| 1.7 – 3.2 с | Бег к первой публикации | Галоп, squash-stretch, шлейф, тень по «полу» |
| ≈ 3.3 с | Посадка на публикацию | Цель — медиа-блок первой карточки: кот приседает, карточка подсвечивается, пыль |
| 3.7 – 4.8 с | Карабканье | Зигзаг «по стене» карточки, следы когтей, кромка аватара светится |
| ≈ 4.8 с | Кот на месте фото профиля | 3D-кот уходит, буква «O.» гаснет, в аватаре включается 2D-кот, страница становится резкой |
| далее | Живая лента | 8 публикаций, у каждой свой кот |

## Коты в публикациях

| № | Публикация | Сценарий |
| --- | --- | --- |
| — | Фото профиля (шапка) | танцует, пускает ноты |
| 1 | ONE DOPE · Аудиорелизы | **танец**: покачивание, подпрыгивания, флип, ноты |
| 2 | BOTCONTROL | **царапает** окошко с логотипом проекта (царапины вспыхивают) |
| 3 | ТИТАН | **вылезает** из границы аватара и **гуляет по верхней кромке** карточки, оставляя следы лапок |
| 4 | VISION AUDIO | играет: гоняется за светящейся точкой-волной |
| 5 | ПОДРАБОТКА.МСК | выглядывает из-за края аватара и моргает |
| 6 | ЛЕСНОЕ·АФИША | бегает за курсором внутри аватара |
| 7 | ПЕРЕКУР+ | дремлет, «дышит», пускает «z-z-z» |
| 8 | EX | прыгает к кнопке лайка |

Все коты — один и тот же силуэт-логотип (`docs/cat-mark-ink.png`, цвет `#2b3a86`),
анимация — CSS-трансформации в rAF с разными фазами, поэтому коты не синхронны.
Коты тикают только когда страница открыта и карточка в зоне видимости
(IntersectionObserver), поэтому лента не грузит процессор при прокрутке.

## Обратный сбор

Клик «К пилюлям» → коты замирают, главный кот убегает из аватара обратно в капсулу,
крышка садится соосно с «чпок», тема гаснет, страница закрывается и прокрутка
сбрасывается. Состояние возвращается в `ready` — цикл можно повторять.

## Горячие клавиши и отладка

```
?debug=1   — панель таймлайна (состояния капсул, состояние кота, число котов, FPS)
?slow=1    — замедление ×0.32
1 / 2      — открыть красную / синюю капсулу
Esc        — собрать капсулы обратно
```

Из консоли: `window.__capsules` (движок пилюль) и `window.FEED` (лента и коты).

## Как это перенести в Next.js

Исходники разбиты по блокам в `docs/src-feed/`:

| Файл | Что внутри |
| --- | --- |
| `feed-posts.js` | данные 8 публикаций (совпадают с `src/data/posts.js`) |
| `feed.html` | разметка страницы Dope (шапка + контейнер ленты) |
| `feed-cats.js` | сборка карточек, `CatActor` (8 сценариев), `CatDirector` |
| `feed-bridge.js` | мост «движок капсул ↔ лента»: посадка, карабканье, прибытие, сбор |
| `feed.css` | стили ленты, аватаров-котов, окошек с логотипами, кромки карточки |
| `dope-app.js` | движок пилюль целиком (в нём правки траектории кота) |
| `base-style.css` | базовые стили концепта (капсулы, темы, страницы) |

Порядок переноса:

1. `Feed.js` / `PostWrapper.js` заменить разметкой из `feed.html` и рендерить карточки
   из `demoPosts` (поля `cat`-сценария можно добавить в `src/data/posts.js` как `catScript`).
2. `CatActor` + `CatDirector` вынести в `src/components/live-feed/` и подключать как
   клиентский компонент; данные сценария — из поста.
3. Вызовы `FEED.onCatLandedOnPost` / `onCatArrived` / `onCatLeaving` дёргать из
   `V3Experience` в тех же точках, где сейчас `revealPage('blue')` и `collectPill`.

## Что ещё можно докрутить

- собственные SVG-сцены «окошка с логотипом» для царапанья (сейчас это знак проекта);
- больше сценариев (кот приносит почту, спит на кнопке, листает карусель артов);
- реакция на лайк: кот в этом посте подпрыгивает, когда пользователь ставит лайк;
- сохранение состояния «кот уже дома», чтобы при повторном открытии он сразу сидел в аватаре.
