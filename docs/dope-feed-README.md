# ONEDOPEA · полная страница Dope из синей капсулы (прототип)

Автономный HTML-прототип: из синей пилюли выпрыгивает кот-логотип, приземляется на
**первую публикацию**, карабкается вверх и занимает **место фото профиля**. После этого
лента оживает: в «фото профиля» каждой публикации живёт кот со своим сценарием.

интернет не нужен (обложка аудио-релиза SoundCloud подгружается с их CDN, но при
отсутствии сети показывается аккуратная заглушка «ENOUGH Z»).

## Что происходит по шагам

| Время | Сцена | Что видно |
| --- | --- | --- |
| 0 – 1.2 с | Синяя капсула откручивается | Крышка сходит, внутри «зев» капсулы |
| ≈ 1.2 с | Превью ленты | Страница Dope уже видна, но размыта — коту есть куда бежать |
| ≈ 1.3 с | Кот вылезает | Присед в горлышке, толчок, масштаб 100 % |
| 1.5 – 2.2 с | Полёт | Дуга к первой публикации: лапы поджаты/раскрыты, хвост в струю, корпус тянется по траектории |
| ≈ 2.3 с | Посадка | Сплющивание на карточке, оглядка, пыль, карточка подсвечивается |
| 2.5 – 4.5 с | Карабканье | Кот разворачивается к левой кромке карточки, встаёт «на стену» и перехватывает лапами вверх, следы когтей |
| ≈ 4.7 с | Кот на месте фото профиля | Буква «O.» гаснет, в аватаре включается живой векторный кот, страница становится резкой |
| далее | Живая лента | 8 публикаций, у каждой свой кот |

## Коты в публикациях

| № | Публикация | Сценарий |
| --- | --- | --- |
| — | Фото профиля (шапка) | танцует, пускает ноты |
| 1 | ONE DOPE · Аудиорелизы | **танец**: покачивание, подпрыгивания, флип, ноты |
| 2 | BOTCONTROL | **царапает** окошко с логотипом проекта (царапины вспыхивают) |
| 3 | ТИТАН | **вылезает** из рамки аватара и **бегает по верхней кромке** карточки, оставляя следы лапок |
| 4 | VISION AUDIO | играет: гоняется за светящейся точкой-волной |
| 5 | ПОДРАБОТКА.МСК | выглядывает из-за края аватара и моргает |
| 6 | ЛЕСНОЕ·АФИША | бегает за курсором внутри аватара |
| 7 | ПЕРЕКУР+ | дремлет, «дышит», пускает «z-z-z» |
| 8 | EX | прыгает к кнопке лайка |

Все коты — один и тот же **векторный** кот (`#2b3a86`, собран из SVG-фигур в
`feed-rig.js`), а не растровый спрайт: у него гнутся лапы, хвост, корпус и голова,
поэтому вблизи он остаётся резким на любом экране. Каждому коту достаётся свой
`CatRig`, позы считаются от общей фазы, но с разными сдвигами — коты не синхронны.
Коты тикают только когда страница открыта и карточка в зоне видимости
(IntersectionObserver), поэтому лента не грузит процессор при прокрутке.

## Обратный сбор

Клик «К пилюлям» → коты замирают, главный кот выпрыгивает из аватара и уходит
дугой в «зев» капсулы (страница к этому моменту уже скрыта, поэтому точку старта
риг запоминает сам: `HERO.state.home`), крышка садится соосно с «чпок», тема
гаснет, страница закрывается и прокрутка сбрасывается. Состояние возвращается в
`ready` — цикл можно повторять сколько угодно раз.

## Горячие клавиши и отладка

```
?debug=1   — панель таймлайна (состояния капсул, состояние кота, число котов, FPS)
?slow=1    — замедление ×0.32
1 / 2      — открыть красную / синюю капсулу
Esc        — собрать капсулы обратно
```

Из консоли: `window.__capsules` (движок пилюль) и `window.FEED` (лента и коты).

## Как это перенести в Next.js

Исходники разбиты по блокам в `docs/src-feed/`:

| Файл | Что внутри |
| --- | --- |
| `head.html` | `<head>`: мета, шрифты, кнопка «Скачать», открывающие теги |
| `body.html` | разметка сцены: WebGL-контейнер, страницы, слой эффектов |
| `feed-posts.js` | данные 8 публикаций (совпадают с `src/data/posts.js`) |
| `feed-rig.js` | `buildCatSVG()` + `CatRig`: суставы, позы `poseRun / poseFly / poseClimb / poseScratch / poseDance / poseLeap / poseLand / poseSit / poseIdle` |
| `feed-cats.js` | сборка карточек, `CatActor` (8 сценариев), `CatDirector` |
| `hero-cat.js` | `HERO` — главный кот: `launch / flee / update / reset`, состояния `emerge → leap → land → climb → flee` |
| `feed-bridge.js` | мост «движок капсул ↔ лента»: посадка, карабканье, прибытие, сбор |
| `feed.css` | стили ленты, аватаров-котов, окошек с логотипами, кромки карточки |
| `dope-app.js` | движок пилюль целиком (капсулы, сцены, связка с котом) |
| `base-style.css` | базовые стили концепта (капсулы, темы, страницы) |
| `build.py` | сборщик: склеивает всё в `docs/dope-feed-concept.html` |
| `feed.html` | старая разметка (легаси, в сборке не участвует) |

Пересобрать страницу после правок:

```bash
python3 docs/src-feed/build.py          # сухой прогон, печатает размер
python3 docs/src-feed/build.py write    # записывает docs/dope-feed-concept.html
```

`base-style.css`, `feed.css` и `feed-posts.js` — дословные копии из опубликованной
вёрстки: правим их только вместе с исходниками Next.js, иначе разъедется дизайн.

Порядок переноса:

1. `Feed.js` / `PostWrapper.js` заменить разметкой из `body.html` + `feed.css` и
   рендерить карточки из `demoPosts` (поля `cat`-сценария можно добавить в
   `src/data/posts.js` как `catScript`).
2. `feed-rig.js` + `feed-cats.js` (`CatActor`, `CatDirector`) вынести в
   `src/components/live-feed/` и подключать как клиентский компонент; данные
   сценария — из поста. `hero-cat.js` — отдельный клиентский хук поверх
   `FEED`, он не знает про Three.js.
3. Вызовы `FEED.onCatLandedOnPost` / `onCatArrived` / `onCatLeaving` дёргать из
   `V3Experience` в тех же точках, где сейчас `revealPage('blue')` и `collectPill`.

## Что ещё можно докрутить

- собственные SVG-сцены «окошка с логотипом» для царапанья (сейчас это знак проекта);
- больше сценариев (кот приносит почту, спит на кнопке, листает карусель артов);
- реакция на лайк: кот в этом посте подпрыгивает, когда пользователь ставит лайк;
- сохранение состояния «кот уже дома», чтобы при повторном открытии он сразу сидел в аватаре;
- звук: «чпок» капсулы, мягкий удар при посадке и шорох когтей по кромке карточки.
