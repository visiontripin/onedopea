# ONEDOPEA

Портфолио и проекты. Здесь живут две вещи:

| | Что это | Где |
|---|---|---|
| **Портфолио** | интерактивная главная страница: каналы, боты, ссылки | [`index.html`](index.html) |
| **EX** | документальный эксперимент о том, сколько людей человек может знать лично | [`EX/`](EX/) |

---

## EX — коротко

Один человек собирает незнакомых людей на вечерние круги по 10–25 человек,
слушает каждого по две минуты, говорит с каждым лично и фиксирует всё на видео.
Затем считает: кого запомнил через день, через месяц, что изменилось с настроением
и вниманием. 100 человек → 500 → 1 000.

Стартовый бюджет — **0 €**. Первые 1 500 контактов проходятся на телефон, в библиотеке,
с распечатанными согласиями. Деньги нужны только для масштаба.

```
Каждый блогер говорит «привет, друзья» людям, которых не знает.
EX начинается с того, что эта ложь названа вслух.
```

**Начать отсюда:**

| Если вы… | Открывайте |
|---|---|
| хотите понять идею за 5 минут | [`EX/index.html`](EX/index.html) |
| смотрите презентацию | [`EX/deck.html`](EX/deck.html) — ← → листать, `P` — в PDF |
| хотите прийти на вечер | [`EX/join.html`](EX/join.html) |
| запускаете проект руками | [`EX/docs/LAUNCH.md`](EX/docs/LAUNCH.md) |
| читаете всё подряд | [`EX/docs/index.html`](EX/docs/index.html) |

## Локальный запуск

Ничего устанавливать не нужно, кроме Python 3.9+.

```bash
make serve            # сайт на http://localhost:8000
make build            # markdown → html
make check            # ссылки, реестр, счётчики
make package          # собрать _site/ для публикации
make all              # build + check + package
```

Или без make:

```bash
python3 EX/tools/build_site.py      # собрать страницы документов
python3 EX/tools/check_links.py     # проверить ссылки и реестр
python3 -m http.server 8000         # посмотреть локально
```

## Публикация

Сайт раздаётся как статика: `index.html` + папка `EX/`. Два варианта:

1. **GitHub Pages через Actions** (в репозитории есть workflow):
   Settings → Pages → Source: *GitHub Actions*. Каждый push в `main` собирает
   `_site/` и публикует.
2. **Любой статический хостинг** (Cloudflare Pages, Netlify, Vercel):
   команда сборки — `python3 EX/tools/build_site.py`, папка — `_site`
   (соберите её командой `make package`).

Перед публикацией замените контакты: `EX/join.html` (Telegram и e-mail) и
`EX/docs/PRESS.md` (§ 8).
