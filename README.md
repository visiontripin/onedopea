# ONEDOPEA · v3

Живой адрес: **<https://visiontripin.github.io/onedopea/>**

Актуальная третья версия сайта **ONEDOPEA**:

- **`/` — 3D Red & Blue Capsules (`capsules.html`)** — минималистичный вход: 3D-капсулы и подпись «Выбирай!» снизу.
  - **Красная капсула → `One`** (`matrix.html` — 7-канальная ЭЛТ-сцена)
  - **Синяя капсула → `Dope`** (светлая лента со всеми 7 проектами: **BotControl**, **ТИТАН**, **Vision Audio**, **Подработка.МСК**, **Лесное·Афиша**, **Перекур+** и **EX**)
- **`docs/capsules-v2-concept.html`** — доработанный автономный концепт интро-сегмента
  (плотный гель, замок ±20 %, матрица из высыпавшихся глифов, кот → аватар, чистый
  обратный сбор). Разбор и тайминг — `docs/capsules-v2-README.md`,
  раскадровка — `docs/capsules-v2-storyboard.png`.
- **`docs/dope-feed-concept.html`** — прототип **полной страницы Dope** из синей пилюли:
  кот выпрыгивает, садится на первую публикацию, карабкается на место фото профиля, и
  в «фото профиля» каждой из 8 публикаций живёт кот со своим сценарием (танец, царапанье
  логотипа, прогулка по кромке карточки и т. д.). Разбор — `docs/dope-feed-README.md`,
  раскадровка — `docs/dope-feed-storyboard.png`, галерея сценариев — `docs/dope-cats-gallery.png`.
- **`/EX/`** — документальный эксперимент EX (`EX/index.html`, презентация `EX/deck.html`, заявка `EX/join.html`, протокол и реестр).
- **`old/`** — архив предыдущих версий сайта (`v1`, `v2`, старые переключатели).

## Локальный запуск и сборка

```bash
npm install
npm run dev          # локальная разработка на 0.0.0.0:3000
npm run build:pages  # статический экспорт Next.js в корень для GitHub Pages
python3 EX/tools/check_links.py  # проверка целостности ссылок и реестра EX
```
