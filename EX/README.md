# EX

**Подпроект репозитория ONEDOPEA.**
Эксперимент: что происходит с человеком, который лично знакомится с незнакомыми
людьми — 100, 500, 1 000, 1 500. Каждая встреча фиксируется на видео и попадает
в открытый реестр.

```
EX — это и «эксперимент», и «ex»: тот, кем ты стал для предыдущих.
```

Стартовый бюджет — **0 €**. Формат старта — вечерний круг на 10–25 человек.

## Сборка и проверка

```bash
make serve     # сайт на http://localhost:8000
make build     # markdown → html
make check     # ссылки, реестр, счётчики
make package   # _site/ для публикации
```

Без make:

```bash
python3 EX/tools/build_site.py
python3 EX/tools/check_links.py
python3 EX/tools/package_site.py
python3 EX/tools/ex_math.py      # пересчитать таблицы в MATH.md
```

## Главные правила проекта (коротко)

1. Подопытный не может быть продюсером: тот, кто проходит протокол, не решает,
   что снимать и как считать.
2. Никому не обещаем дружбу. На вечере двадцать человек, и ведущий честно говорит,
   что запомнит не всех.
3. Согласие подписывается **до** включения камеры. Отзыв — в любой момент и бессрочно.
4. Каждый выпуск заканчивается числом, а не эмоцией.
5. Никаких «учёные доказали»: один человек — это N=1, и это сказано в протоколе.

Подробно — [`docs/ETHICS.md`](docs/ETHICS.md) и [`docs/PROTOCOL.md`](docs/PROTOCOL.md).
