# Архив предыдущих версий и черновиков (`old/`)

Здесь сохранены ранние редакции сайта и автономные стенды, убранные из корня GitHub Pages:

- `old/v1/` — первая одноэкранная ЭЛТ-сцена (`index.html`), доска изменений (`plan.html`), прототип кабинета (`account.html`), `content.json`, `ONEDOPEA-v3-phone.zip`.
- `old/v2/` — предыдущая версия сайта (`One` + `Dope` на 3 проекта) и автономная сборка `index-v2.html`.
- `old/hub/` — прежние экраны выбора версий и стилей (`VersionHub.js`, `StyleGate.js`, `intro.html`).
- `old/segment/` — автономный стенд отладки сегмента пилюль и сборки страниц из 3D-фрагментов (`capsules-segment-standalone.html`, `capsules-segment.html`, `capsules-segment.zip`, `preview-server.py`), интегрированный в боевую сборку `src/lib/capsules-engine.js` + `src/components/V3Experience.js`.
